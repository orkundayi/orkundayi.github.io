Orkun Dayı · Flutter Developer | Full-Stack Developer

Flutter Developer olarak mobil ve web uygulamaları geliştiriyorum. Flutter ve Dart ana uzmanlık alanımın yanında Firebase, REST API entegrasyonları, SQL veri yapıları ve .NET tabanlı backend geliştirme süreçleriyle çalışıyorum. OverPay projesinde ödeme, satış, raporlama, müşteri entegrasyonları, GİB entegrasyonu ve VKN/TCKN sorgulama akışlarına yönelik kullanıcı arayüzleri geliştirdim. Full-stack bakış açısıyla temiz kod, sürdürülebilir mimari, performanslı ekran yapıları ve gerçek iş süreçlerine uygun ürünler geliştirmeye odaklanıyorum.
